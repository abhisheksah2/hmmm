# Hinglish Translator

**Hinglish Translator** is a user-friendly web app that helps you translate common English idioms into their equivalent Hindi proverbs (कहावतें), in both Devanagari and Romanised Hindi. Whether you're learning, curious about Hinglish, or want to explore the cultural richness of idioms and proverbs, this tool is for you!

## Features

- **Translate English Idioms**  
  Search for any English idiom and instantly get its Hindi proverb, romanised script, and meanings in both languages.

- **Browse Idioms by Category**  
  Filter and explore by theme—like Food, Nature, Emotion, Action, and Quotes.

- **Random "Surprise Me"**  
  Can't decide? Let the app pick an idiom for you to discover!

- **Favorites**  
  Save your favourite idioms locally (browser-based).

- **Pronunciation**  
  Hear the correct Hindi pronunciation using speech synthesis.

- **Copy & Share**  
  Easily copy translations to the clipboard or share them.

- **Responsive Design**  
  Works beautifully on mobile, tablet, and desktop.

## Getting Started

**Open the app**  
   Simply open `index (1).html` in your favourite browser. No build tools required!

   ```
   .
   ├── index (1).html
   ├── styles.css
   └── script.js
   ```

## File Structure

- `index (1).html` – Main HTML file containing UI structure
- `styles.css`      – App styling (responsive and modern)
- `script.js`       – Logic, database, and interactivity (all on frontend)

## How It Works

- Type an English idiom (or pick from browse/random)
- View the Hindi proverb, its romanisation, meaning & usage
- Listen, copy, or favourite for later!

The project uses a static in-browser idiom-proverb database. All logic is performed client-side, making it lightweight and privacy-friendly.
